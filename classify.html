Neural networks that answer inside one eth_call

Two binarized networks run as contracts. Each classification on this page is a free, read-only call sent to two independent RPC operators. The answers are integers, so the two nodes either agree exactly or they don't.

Check it yourself

Read the model's identity straight from the chain with Foundry. The second value is the IR hash: the SHA-256 that pins the model's architecture and weights.

How the deployments were verified (read-only, 2026-09-28, on both nodes): the runner's code was compared byte for byte with the build of its Solidity source, every weight chunk with the model files the IR hash names, and 100 sampled test images per model with the reference runtime. All matched.
