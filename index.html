1 · the idea1 · 理念与设计

      
A model you can audit, because it is only integers只由整数组成，所以能被审计的模型

      

        Most AI runs on a server you have to trust. A contract cannot work that way: it has no floating point and no network, and everything it computes must come out the same on every node. BNNX takes that as its design rule. A network is trained in PyTorch, then turned into integers: weights of +1 or −1, thresholds, small integer levels. Those integers are the model, and a reference program and a contract compute exactly the same ones.
        大多数 AI 跑在你只能选择相信的服务器上。合约做不到这样：它没有浮点数，也没有网络，算出的每一个结果在每个节点上都必须相同。BNNX 把这当成设计规则：网络在 PyTorch 里训练，然后变成整数：+1 或 −1 的权重、阈值、几位的整数电平。这些整数就是模型本身，参考程序和合约算出的是完全相同的整数。
      


      

        

          
1 · integers all the way down1 · 全程都是整数

          

            
One binarised neuron. Flip any input or weight: the sum of the products is an exact integer, and the output is +1 when it reaches zero. A whole layer is many of these, so the contract needs only adds and compares.一个二值化的神经元。翻转任意输入或权重：乘积之和是精确的整数，和大于等于 0 时输出 +1。一整层就是很多个这样的神经元，所以合约只需要加法和比较。

            

          

        


        

          
2 · the same answer everywhere2 · 到处都是同一个答案

          

            
The trained network becomes one fixed integer form, the IR. A reference program runs it on a laptop; the contract runs it on chain. Both return the same label and the same score for every class, and any node can be asked.训练好的网络变成一种固定的整数形式，叫 IR。参考程序在笔记本上运行它，合约在链上运行它。两边对每个类别返回同样的标签和同样的得分，谁都可以去问任意一个节点。

            
          

        

      


      

        

          
3 · free to read, easy to compose3 · 读取免费，容易组合

          

            Anyone can call a model with a read-only eth_call: no wallet, no fee. Another contract can call it too, inside a transaction, and act on the answer. That is how the gomoku game on this page works: the game contract asks the network for each move in the player's own transaction.
            任何人都可以用只读的 eth_call 调用模型：不需要钱包，也不收费。别的合约也可以在交易里调用它，并按答案行动。这页上的五子棋就是这样做的：对弈合约在玩家自己的交易里向网络要每一步棋。
          

          
    
            
  • Cheap arithmetic. A ±1 multiply-add costs about 0.65 gas and an int8 one about 6.1 (measured, unoptimised), so small networks fit in one call.便宜的算术。一次 ±1 乘加约 0.65 gas，int8 约 6.1 gas（实测，未优化），所以小网络放得进一次调用。
    • 
            
  • Weights are contract code. They live in immutable data contracts of at most 24,000 bytes and are read with EXTCODECOPY: no storage, no owner.权重就是合约代码。它们放在不可变的数据合约里，每个最多 24,000 字节，用 EXTCODECOPY 读取：没有存储，没有管理员。
    • 
            
  • Pure by construction. The runner reads no state and no block data, so its output depends on the input only.从构造上就是纯函数。运行器不读任何状态和区块数据，所以输出只取决于输入。
    • 
            
  • Every claim can be checked. The IR hash names the model, and bnnx verify compares the contract's code and data with it.每个说法都能核对。IR 哈希给模型命名，bnnx verify 把合约的代码和数据与它逐项比对。
    • 
          

        

        
      


      
Where BNNX fits in TapeOutBNNX 在 TapeOut 里的位置

      

        TapeOut already puts a site's front end on chain (DeWeb) and its state in a container. What a site cannot yet do is call logic that is just as verifiable. BNNX is the project that supplies that missing layer: a trained model becomes a pure contract that a page, a circuit's owner or another contract can call, and anyone can check.
        TapeOut 已经把网站的前端放上了链（DeWeb），把状态放进了容器。网站目前还做不到的，是调用同样可验证的逻辑。BNNX 就是补上这一层的项目：训练好的模型变成一个纯函数合约，页面、电路持有人或别的合约都能调用，任何人都能核对。

The toolkit工具包

      

        

          
Python bnnx

          
Train binarised and few-bit networks in PyTorch with bnnx.nn. Reproducible CPU training; export checks the IR against PyTorch before it writes a file.用 bnnx.nn 在 PyTorch 里训练二值和多位网络。CPU 训练可复现；导出时先对照 PyTorch 检查 IR，再写文件。

        

        

          
The command line命令行

          
12 commands: inspect, compile, deploy, verify, call, replay, import-qonnx and more. Your wallet signs; no command takes a private key.12 个命令：inspect、compile、deploy、verify、call、replay、import-qonnx 等。用你自己的钱包签名，没有任何命令接受私钥。

    Limits you should know about需要知道的限制
    
      
    
        
    limits, as measured or specified限制，实测或规定如此
    
        
    
          
    One transaction单笔交易
    At most 16,777,216 gas on BSC. A model that needs more only runs as a read-only call: the CIFAR-10 network of 2026-10-18 fits (16.1M gas), the 44.3M-gas CNV network does not.BSC 上最多 16,777,216 gas。需要更多的模型只能作为只读调用运行：2026-10-18 的 CIFAR-10 网络放得下（16.1M gas），44.3M gas 的 CNV 网络放不下。
    
          
    One read-only call一次只读调用
    About 50M gas on public nodes and about 286M on BNB Chain's own node (measured 2026-09-28). Nodes differ, so the demos ask two.公共节点约 50M gas，BNB Chain 官方节点约 286M（2026-09-28 实测）。节点各不相同，所以演示里同时问两个。
    
          
    Size大小
    Data contracts hold at most 24,000 bytes each. A sequential model takes up to 16 of them, a graph model up to 64 (about 1.5 MB).每个数据合约最多存 24,000 字节。顺序模型最多 16 个，图模型最多 64 个（约 1.5 MB）。
    
          
    Arithmetic运算
    Weights are ±1 or int8. Activations are ±1 or 2 to 4 bits. No floating point; batch normalisation is folded into thresholds. Layers have at most 256 channels; convolutions are 3×3 or 1×1, stride 1 or 2.权重是 ±1 或 int8。激活是 ±1 或 2 到 4 位。没有浮点数；批归一化折进阈值。每层最多 256 个通道；卷积是 3×3 或 1×1，步长 1 或 2。
    
          
    Input and output输入和输出
    The input is uint8 values in height, width, channel order, exactly the length modelInfo() says. The output is one integer score per class; ties go to the lowest index.输入是按高、宽、通道顺序排列的 uint8，长度必须正好等于 modelInfo() 给出的值。输出是每个类别一个整数得分；平局取序号最小的。
    
          
    Cost成本
    About 0.65 gas per ±1 multiply-add and 6.1 per int8 one (measured, unoptimised). Storing a model costs about 0.0105 BNB per MiB at 0.05 gwei (estimate).每次 ±1 乘加约 0.65 gas，int8 约 6.1 gas（实测，未优化）。存一个模型每 MiB 约 0.0105 BNB（按 0.05 gwei 估算）。
